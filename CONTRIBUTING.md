# Contributing to CHATEAMS

Thank you for wanting to improve **CHATEAMS**! Anyone is welcome to modify the code, fix bugs, or add new features.

## How to Make Changes
1. **Fork** this repository on GitHub.
2. Open `www/index.html` in any code editor (like VS Code).
3. Test your changes simply by opening `www/index.html` in your web browser.
4. Commit your changes and open a **Pull Request** describing what you added or improved.

## Project Structure
- `www/index.html` — Main app UI, CSS, and JavaScript logic.
- `www/manifest.json` & `www/sw.js` — PWA install and offline support.
- `www/icon.svg` — App icon.
- `.github/workflows/build-apk.yml` — Automated Android `.apk` build workflow.
